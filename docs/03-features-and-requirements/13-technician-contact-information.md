13. Technician Contact Information
Purpose

This feature allows the customer to view basic information about the assigned technician after the Admin assigns a technician to the service.

Version 1 Information

The customer may be able to view:

Technician name
Technician specialization
Assigned service
Contact number, if the company allows it
Multi-Service Booking

If one booking contains multiple services, the customer may see a different technician for each service.

Example:

AC Cleaning → AC Technician
Sofa Cleaning → Cleaning Team
Curtain Installation → Handyman
Important Rules
Technician information appears only after assignment.
The Admin controls the technician assignment.
The contact number should appear only if the company decides to share it.
Live technician tracking is not included in Version 1.
Technician ratings and direct chat can be added later.
