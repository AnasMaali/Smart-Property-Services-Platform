# Technician Assignment

## Purpose

This document defines how the Admin / Service Management Team assigns the suitable technician or employee to each service inside a paid booking request.

---

## Version 1 Scope

In Version 1, technicians do not have separate system accounts.

The admin assigns technicians manually from the admin management interface and updates the service progress on their behalf.

---

## Assignment Rule

A booking may contain one service or multiple services.

The admin can assign:

* One technician to the full booking, if all services can be completed by the same person.
* Different technicians to different services, if the booking contains services from different categories.

Example:

* AC Cleaning → AC Technician
* Sofa Cleaning → Cleaning Team
* Curtain Installation → Handyman

---

## Technician Information

When assigning a technician, the admin should be able to view:

* Technician name
* Technician specialization
* Availability
* Contact number
* Current assignment status

---

## Assignment Flow

1. The paid booking appears in the admin management interface.
2. The admin reviews the services inside the booking.
3. The admin chooses the suitable technician for each service.
4. The technician assignment is saved in the system.
5. The admin updates the service status during execution.
6. The booking is completed after all required services are finished.

---

## Important Rules

* Only the admin can assign technicians in Version 1.
* A technician should be assigned based on specialization and availability.
* Different services inside one booking may have different technicians.
* Technician accounts and dashboards can be added in Version 2.
